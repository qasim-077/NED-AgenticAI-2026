The one idea for today

🧒 Like you're 10: AI is a super-fast storyteller that guesses the next word really well. It sounds sure even when it's guessing. So you give it the right papers, and you check its homework.

🔮It predicts
It continues text with likely next pieces. It never opens a database of facts.
📄Shape helps
Markdown marks show which line is which — but a neat page is only as right as its lines.
🧭4Ds
Delegation, Description, Discernment, Diligence — same four skills, different timing when AI works alone.
⚖️Judge it
Claim → basis → assumptions → what would change it → who decides. A fluent answer is a draft.

0.1.2 · Tokens — why "strawberry" is hard

🧒 The model reads pieces of words (tokens), not letters. It's like reading words cut into puzzle pieces — you can't easily count the r's inside a piece.

strawberryBrightline approvalreconciliationشکریہ بہت

Illustrative split. Rule of thumb: ~4 tokens ≈ 3 English words. Urdu, Arabic, Hindi, Chinese usually need more tokens per word → fill the window faster and cost more.

Why it sounds sure — and agrees with you

📻Confidence = style
People rated confident, fluent answers higher, so the model learned one sure, tidy voice for every answer. Like a radio presenter reading the forecast in the same calm voice, right or wrong.
🙂Sycophancy
"Isn't the limit $10,000?" puts $10,000 in the window. The trained lean toward agreeing may make it say yes.
🕳️Hallucination
Nothing inside asks "Am I sure?". When neither source has the fact, it fills the gap with a fluent guess. A sure tone is a style, not a source.

The jagged frontier

Skill is uneven — and not ordered by difficulty. Strong on hard tasks still needs checking on easy ones. Re-test every new model.

💭 Thinking
The model writes its working before answering. Often better on hard problems — but it's more predicted text, not a truth-checker.
🎚️ Effort
How much working it writes. More effort = more time & tokens. No new source, no checker.
🔌 Connector / MCP
Links AI to your other apps (email, drive) — only what you allow. Many use the open Model Context Protocol.
🧰 Skill · Plugin
Skill = saved written procedure loaded when needed. Plugin = a package of skills + connectors. Each addition is a choice.

Pick the shape for the next reader

🧒 An airline keeps one trip record and prints boarding passes from it. Seat changes? Fix the record, never a pass with a pen.

🤖An AI, or you later
→ Markdown page. Plain text that keeps its shape anywhere; easy to check line by line.
✍️A person who signs
→ Word or PDF. Prints and files; a PDF looks the same everywhere.
📊A spreadsheet
→ CSV table. One row per record, one column per value.
🖥️A person on screen
→ Web page. Styled tables, charts, buttons. Make it from the checked page.

0.3.1 · Three ways to work with AI

🧒 Dinner three ways: give a cook a recipe (automation) · cook together, tasting as you go (augmentation) · hire a cook for nights you're out (agency).

ModeWho picks the next stepAre you there?
AutomationYou, in your instructionsWhen you ask + when it returns
AugmentationYou and AI, turn by turnEvery turn
AgencyThe AI, inside what you set upNo — result arrives later

A mode is not a permission. The monthly reconciliation runs in agency — and may still change nothing at all.
